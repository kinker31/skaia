# Generalized Skaia Roadmap

##First Orders
* Completely jettison anything realted to Heretic and Hexen; Some related code might be re-introduced if need be, but this port will be *only* for Doom goinf forwards. Chex Quest and HacX will not be supported either, as much as I like Chex Quest.
* Get rid of pre-1.9 excecutable compatibility, strict demo support isn't something I'm going to be aiming for going forwards.
* Move anything related to the Crispy Doom setup excecutable into another in-game menu, kinda like what Boom does.

## The Prospit Mapping Format
* Re-organize and rebuild the vanilla linedef sepcials from the ground up; Maybe also add a few bits and bobs from MBF21 for this as well. **Generalized Linedefs will NOT be added.**
* Implement a parameter (or two) for every (or most) unique linedef special(s).
* Implement the 16th bit of the special parameter as customized linedefs, and add a ACS-like scripting language to let people customize what any of the 16K+ actions can do.
* 

## The Derse Codepointer Suite
* Implement the BEX DeHacked format, or at least as much of it as possible.
* Implement a basic form of DEHExtra? DSDHacked? Just increase the available amount of codepointers by a lot.
* Add the monster-related codepointers.
* Add the weapon-related codepointers.
* Add most of the other codepointers. (These three can be worked on at the same time, or can be swapped between as needed.)

## Far-flung Future Developments
* Potential Invasion-style gamemode
* Optimized Multiplayer support
* New difficulty/difficulties
* Many, many, *many* easter eggs.

None of these are set in stone, plans and general ideas could change at a moment's notice.
